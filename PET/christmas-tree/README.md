# Праздничная ёлка

[Скачать пакет `.pet`](https://github.com/GamoffVad/Sputnik/releases/download/v1.3.28.21/Christmas-Tree-10.pet) · [Тема](theme.json) · [Манифест](package-manifest.json)

Десять анимаций, 1450 кадров 960×960 с прозрачностью при 24 кадрах в секунду.
Ёлка, подарки, украшения, эффекты и мягкая тень сохранены без уменьшения мастер-кадров.
У всех десяти движений первый и последний кадры пиксельно совпадают с `reference.png`.
Каждое движение разбито на пять атласов, общий нейтральный кадр используется для переходов.

Палитра «Праздничная хвоя»: зелёный акцент `#91B879`, поверхность `#273328`, фон `#182119`.
Для её применения включите «Применить палитру питомца» в библиотеке.

Импорт: «Питомцы» → плюс → скачанный `Christmas-Tree-10.pet`.
Нужна версия Спутника, поддерживающая пакеты схемы 3 размером до 1 ГиБ.
Пакет проверен штатным импортом Windows; импорт на физическом Mac отдельно не проверялся.
Размер пакета: 894,797,977 байт. Контрольная сумма — в [SHA256SUMS.txt](SHA256SUMS.txt).
