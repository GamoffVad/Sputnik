# Пакеты текущей библиотеки

[Полный каталог](../../PET/README.md) содержит ровно десять установленных питомцев. `catalog.json` фиксирует актуальные имена, число движений, ссылки, размеры и SHA-256 пакетов из выпуска `pets-2026-11-22`.

`Build-Pet-Packages.ps1` скачивает только этот состав и проверяет размер и SHA-256 каждого файла. Можно передать `LocalPackages` для использования уже скачанных проверенных пакетов. Клякса встроена в приложение и также доступна отдельным пакетом ресурсов; импортёр защищает её встроенный идентификатор от замены.

Старые выпуски остаются в истории GitHub. Рыцаря-дозорного в текущей библиотеке нет.
