# Проверка Спутника — 17 ноября 2026

Проверены основные сценарии всех разделов на текущем компьютере Windows. Выполненные автоматические проверки завершились успешно. Это не утверждение о стопроцентном покрытии каждой комбинации действий и всех версий Windows.

## Исправления

1. При переключении разделов прежняя страница выгружается, а новая закрашивает всю область содержимого. Для проверки воспроизведены восемь переходов обратно во «Внешний вид»: итоговое изображение попиксельно совпадает с исходным. Поздний ответ чата сохраняется в историю и не появляется поверх настроек.
2. Общие ручки изменения размеров удалены из меню, настроек, чата и других служебных окон. Изменение размера осталось только у заметок: мышью и стрелками клавиатуры. Размер сохраняется при повторном открытии.
3. При подготовке заметки к отправке больше не дублируется номер пункта списка. WPF включал маркер списка в TextRange, после чего код добавлял его повторно. Теперь текст собирается из содержимого строк.
4. Пустой массив choices, неправильная структура JSON и нетекстовое содержимое ответа API обрабатываются понятным сообщением. Техническое исключение индекса и вывод числа вместо ответа устранены.

Интерфейс проверялся настоящими WPF-контролами в отдельном процессе, событиями кнопок/клавиатуры, снимками RenderTargetBitmap и их сравнением. Это не проверка аппаратного композитора на всех GPU.

Проверены формирование запросов и обработка ответов. Совместимость Claude с OpenAI SDK сверена с [официальной документацией](https://platform.claude.com/docs/en/cli-sdks-libraries/libraries/openai-sdk); это не заменяет запрос к реальному аккаунту.

- Файловые диалоги выбора exe/изображения/архива не проходились вручную; обработчики импорта и сериализации проверены отдельно.
- Нет отдельного запуска на Windows 7/10 и физических мониторах с разным DPI. Сборки net48 x64/x86 запущены на текущей системе; геометрия нескольких экранов проверена расчётно.
