# Память анимированных питомцев

Выпуск 1.3.28.28 сохраняет полное исходное разрешение и прозрачность. Память сокращается за счёт удаления ненужных ссылок на большие изображения, без принудительной сборки мусора или очистки рабочего набора.

PNG-файл после декодирования занимает примерно `ширина × высота × 4` байта. Лист ёлки 3840×7680 занимает 112,5 МиБ, хотя сжатый файл существенно меньше. Восемь встроенных листов Кляксы суммарно занимают около 411,75 МиБ при одновременном удержании.

Изменения:

- Вместо накопления старых атласов плеер удерживает текущий лист и предзагрузку следующего.
- Портрет сохраняет пиксели отдельного кадра: `CroppedBitmap` сам по себе продолжает удерживать исходный атлас.
- Переход между движениями сохраняет отдельный кадр предыдущего движения.
- Предпросмотр импорта загружает текущий и следующий лист вместо всех листов движения; при скрытии останавливает таймер, очищает источник изображения и освобождает загрузчик. На медленной границе листов отсчёт времени приостанавливается.

Измерения в отдельных процессах WPF на текущей Windows, один кадр 960×960 из реального PNG-листа ёлки:

| Сценарий | Рабочий набор | Private bytes |
| --- | ---: | ---: |
| Кадр с удержанием атласа | 152,4 МиБ | 124,5 МиБ |
| Независимая копия пикселей кадра | 43,7 МиБ | 15,3 МиБ |

Отдельный тест удержания настоящих листов Кляксы: восемь листов — 450,0 МиБ рабочего набора процесса, два — 145,1 МиБ. Сами пиксельные данные этих восьми листов занимают около 411,75 МиБ; разница с рабочим набором включает инфраструктуру WPF и декодера.

В измерительном режиме выполняется сборка мусора, чтобы сравнить именно удерживаемые ресурсы. В приложении принудительной сборки нет. Это не замер суммарного расхода памяти запущенного Спутника: два полноразмерных листа ёлки сами по себе требуют около 225 МиБ.

Проверки выполняются на маленьких синтетических PNG, включая полупрозрачные пиксели: сравнение всех пикселей, порядок шести кадров в трёх листах, зацикленный предпросмотр и освобождение его ресурсов. Команда:

```powershell
dotnet run --project tests/memory-check/Check.csproj -c Release -- artifacts/memory-check/current
```

Для .NET Framework 4.8 добавьте `-p:Win7=true -p:PlatformTarget=x64 -p:SputnikDirectory=<каталог net48>` перед `--`. Проверка 32-битного процесса запускается отдельно с `x86`.
