# Системный трей Windows

В меню питомца пункт «Скрыть в трей» скрывает питомца и видимые окна приложения. Щелчок по значку Спутника рядом с часами возвращает эти окна и сохраняет положение питомца. Если Windows поместила значок в скрытые, откройте стрелку рядом с часами.

Правой кнопкой по значку: показать/скрыть, быстрый чат, выход. Горячие клавиши и обычный повторный запуск приложения также возвращают его из трея. Закрытие питомца по-прежнему завершает приложение.

При скрытии останавливается таймер отрисовки и время анимации; ручная пауза сохраняется. Напоминания продолжают работать. Быстрый чат закрывается, чтобы поздний ответ не открывал скрытое приложение.

Значок реализован через Shell_NotifyIcon без дополнительных зависимостей. После перезапуска Проводника он добавляется повторно; если панель задач ещё недоступна, выполняются повторные попытки. При завершении приложения значок удаляется.

Проверка `tests/tray-check`: настоящие сообщения значка трея и пункт контекстного меню питомца, скрытие/возврат окон, повторные циклы, сохранение положения и паузы, остановка отрисовки, быстрый чат/выход, восстановление после TaskbarCreated и повторное освобождение ресурсов. Тест использует изолированные окна и не записывает пользовательские данные.
