# Спутник 1.3.28.38 — Windows

Заметки примагничиваются друг к другу при перетаскивании за заголовок: выравниваются по краям и центрам горизонтально и вертикально. Между соседними заметками остаётся зазор 12 пикселей при масштабе экрана 100%. При другом масштабе зазор увеличивается пропорционально.

Привязка действует в пределах 10 пикселей и учитывает только открытые соседние заметки. Удерживайте Alt для свободного перемещения. Двигается только перетаскиваемая заметка; её положение сохраняется автоматически и восстанавливается при открытии.

Сохранены единая кнопка плей/пауза, переключатель случайного порядка, уменьшенный Орёл с собственной палитрой и Бит с 18 анимациями из предыдущего выпуска.
