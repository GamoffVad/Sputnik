# Спутник 1.3.10 для Windows

- Окна настроек, чата, заметок и напоминаний можно изменять за края и углы. Размеры разделов сохраняются между открытиями в текущем сеансе, размеры заметок — также после перезапуска.
- Окна открываются рядом с выбранным пунктом контекстного меню с учётом границ экрана.
- Компактное оформление чата и раздела «Сайты и программы», значки действий с подсказками, микроанимации. Текст ответов можно выделять и копировать.
- «Внешний вид» и «Модель и API» закрываются после успешного сохранения. Ошибки сохранения оставляют окно открытым.
- «Внешний вид → Цвет новых заметок»: прежний цвет по теме питомца или «Автоцвет». Автоцвет чередует пять цветов; существующие заметки сохраняют свои цвета.
- Исправлена перерисовка ползунков и значений в прозрачных окнах. Маркер изменения размера расположен внутри скруглённой рамки.
- Фиксированная область питомца при анимациях и свободное перетаскивание, включая движение вверх при прозрачных полях изображения.
- Сферы формируют дугу вокруг центра видимого персонажа, учитывают отступы и края экрана, отображаются поверх питомца. Открытые сферы не перемещаются вместе с анимацией питомца; повторное открытие обновляет их положение.

## Скачать

- `SputnikSetup-1.3.10-win10-win11-x64.exe` — Windows 10/11, 64 бита; .NET включён.
- `SputnikSetup-1.3.10-win7-x64.exe` — Windows 7 SP1, 64 бита.
- `SputnikSetup-1.3.10-win7-x86.exe` — Windows 7 SP1, 32 бита.
- `Sputnik-win-x64.zip` — переносимая сборка для Windows 10/11, 64 бита.

Установщики Windows 7 содержат автономный пакет .NET Framework 4.8. На Windows 7 SP1 необходимы обновления [SHA-2](https://support.microsoft.com/help/4474419) и [D3DCompiler](https://support.microsoft.com/help/4019990).

Обновление сохраняет пользовательские заметки, настройки и выбранного питомца. Контрольные суммы файлов находятся в `SHA256SUMS.txt`.

Сборки проверены на текущей системе Windows; отдельный запуск на физической Windows 7 не выполнялся.
