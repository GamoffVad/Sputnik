# Спутник 1.3.16 — общий кадр перехода между анимациями

Новый формат пакета v3 хранит один общий прозрачный кадр опорной позы. Приложение показывает его в начале и конце каждой анимации, включая предпросмотр установки. Это позволяет совместить ролики разных исходных разрешений без уменьшения или повторного сжатия исходных PNG-листов.

Лимит пакета увеличен до 512 МиБ и 64 записей ZIP. Проверки путей, геометрии, числа анимаций и размеров PNG сохраняются. Пакеты v1 и v2 по-прежнему поддерживаются.

Три кадра у границ действия плавно связываются с общей позой. Смешиваются цвет и альфа в premultiplied-представлении: непрозрачные участки не становятся полупрозрачными. Настройка сглаживания изображения сохраняется, исходные PNG не меняются.

Сохранено исправление 1.3.15: видимая точка опоры остаётся на месте при смене питомца и изменении размера. Перетаскивание остаётся свободным.

Проверены импорт v3 с 42 записями, неизменность байтов PNG, отклонение некорректных пакетов, попиксельное совпадение переходов в настоящем WPF-рендере на чёрном и белом фоне в четырёх размерах отображения, семь переключений питомцев и 28 изменений размера. Пройдены проверки компонентов WPF и сборка .NET Framework для Windows 7 x64/x86.

В установщике остаётся только Клякса. Отдельные пакеты питомцев находятся в файлах релиза. Пользовательская библиотека, заметки и настройки сохраняются.
