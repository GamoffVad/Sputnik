# Тихий ниндзя — чистый контур подошвы

У «Тихой связки» убран оставшийся светлый след исходной подложки вдоль подошвы. Мягкая тень берётся из общей опорной анимации. Остальные четыре анимации сохранены побайтово.

- Пять анимаций по 120 кадров, 30 кадров/с, четыре секунды.
- Исходные кадры 1280×720 без уменьшения.
- Первые и последние кадры всех пяти анимаций совпадают пиксель в пиксель.
- Палитра приложения сохранена в `.pet`.

Скачайте `quiet-ninja.pet` и откройте его в **Спутник Windows 1.3.14 → Питомцы → Добавить питомца → Обновить питомца**. Предыдущая версия сохраняется в резервной копии. [Установщик 1.3.14](https://github.com/GamoffVad/Sputnik/releases/download/v1.3.14/Sputnik-1.3.14-Windows-10-11-x64.exe).

Пакет также обновлён среди файлов релиза приложения 1.3.14. Установщик приложения содержит только Кляксу. macOS 0.2.2 этот пакет формата 2 не поддерживает.
