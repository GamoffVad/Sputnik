# Спутник 1.3.11

- Исправлена отрисовка при переключении чата и настроек: новая страница закрашивает область содержимого, прежняя выгружается.
- Изменение размера оставлено у заметок; из остальных окон удалены общие ручки изменения размера.
- Исправлено дублирование нумерации списка при подготовке заметки к отправке.
- Некорректная структура ответа API обрабатывается понятным сообщением об ошибке.
- Добавлены воспроизводимые проверки интерфейса, заметок, напоминаний, API, импорта питомцев, сфер и размещения окон.
- Устранено наложение чата на настройки: служебные окна используют нативную отрисовку и скругление Windows.
- Добавлены матовое стекло и регулировка прозрачности фона; текст и значки сохраняют непрозрачность.
- Сферы автоматически появляются при настройке размера, интервала и отступа. Кнопка «Показать сферы» удалена.
- Рамка сферы появляется только при наведении; название показывается в полупрозрачной карточке.
- Убраны рамки фокуса ползунков и кнопок сайтов. Исправлены подсказки открытия и редактирования.
- Выбор значка сайта или программы показывает сетку из 100 изображений; исправлено обрезание значков кнопок.
- Все кнопки «Назад» представлены шевроном влево с доступным названием и подсказкой.
- Рыцарь-дозорный включён в установщики вместе с Кляксой и Кудряшкой.

Установщики:

- `SputnikSetup-1.3.11-win10-win11-x64.exe` — Windows 10/11 x64, со встроенной средой .NET.
- `SputnikSetup-1.3.11-win7-x64.exe` — Windows 7 SP1 x64.
- `SputnikSetup-1.3.11-win7-x86.exe` — Windows 7 SP1 x86.

В оба установщика Windows 7 включён офлайн-пакет .NET Framework 4.8. Пользовательские заметки, настройки и библиотека питомцев при обновлении сохраняются.
