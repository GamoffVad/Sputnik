# Спутник 0.2.1 для macOS

**Скачать:** `Sputnik-0.2.1-macOS-Universal.dmg` — один образ для Apple Silicon и Intel, macOS 13 и новее.

Откройте образ и перенесите **Sputnik** в папку **Программы**, заменив предыдущую версию. Заметки и настройки сохраняются.

## Фото в заметках

- Исправлено извлечение фотографий из сохранённых заметок RTFD: вложения больше не пропускаются из-за способа их хранения.
- «Поделиться текстом и фото…» передаёт системному меню macOS текст и все фотографии. Поддерживаются также заметки только с фото.
- Для каналов со ссылкой отправки, включая Telegram и MAX, добавлен режим «вставить фото»: фотографии копируются в буфер, а текст передаётся через ссылку канала. После выбора чата нажмите **⌘V** и подтвердите отправку в мессенджере.
- Если клиент не принимает фото из буфера, кнопка «Показать файлы фото» открывает подготовленные PNG для прикрепления через скрепку. Само открытие ссылки не отправляет фотографии автоматически.
- Нечитаемое вложение вызывает понятную ошибку вместо незаметной потери фото.

CI проверяет сохранение и повторное чтение двух фото с подписью, заметку без текста, экспорт PNG и отдельный тестовый буфер обмена. Собранный DMG проверяется и запускается на Intel и Apple Silicon. Отправка реальным получателям в Telegram/MAX автоматически не тестируется.

Предварительный выпуск с подписью **ad hoc**, без Developer ID и нотарификации Apple, как и предыдущая версия.
