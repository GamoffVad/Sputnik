# Спутник 1.3.28.32 — Windows

- Опубликован питомец «Орёл»: 12 анимаций, 1164 исходных кадра, прозрачность и мягкая контактная тень.
- Поддерживается масштаб пакета до 2.4, необходимый для согласованного увеличения орла в 1,5 раза. Настройка размера других питомцев сохраняет прежнее поведение.
- «Кругом» использует реальные подъёмы и перестановку лап с переносом веса на неподвижной земле.
- Питомец доступен отдельно в [каталоге PET](../../PET/military-eagle/README.md); пользовательские заметки, подключения и настройки в пакет не входят.

Выпуск основан на 1.3.28.31 и сохраняет исправления значков программ, памяти и удаления питомцев. В пакете орла отключены референсные подстановки и смешивание; проверены 1164 кадра, 144 стыка и DPI 100%/150%. Согласованное небольшое обрезание кончиков крыльев в двух полётах описано в каталоге.

Выпуск включает установщики Windows 10/11 x64 и Windows 7 SP1 x64/x86, переносимую сборку и исходники. Проверки .NET Framework 4.8 выполняются на текущей Windows; отдельного запуска на настоящей Windows 7 не проводилось.
