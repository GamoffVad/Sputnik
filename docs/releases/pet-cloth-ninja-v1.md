# Тканевый ниндзя — 11 анимаций

Ловкий и озорной тканевый ниндзя для «Спутника»: 11 отдельно согласованных анимаций, включая дополнительный динамичный танец.

- Каждый ролик: 960×960, 24 кадра/с, 4 секунды; всего 1056 кадров.
- Все анимации отражены по горизонтали целиком, включая тень и реквизит.
- Зелёный фон удалён; сохранены ткань, свободные концы, мягкая тень, искра с голубым ореолом и бумажная звезда.
- Все 22 начальных и конечных кадра совпадают попиксельно. Упаковка в атласы не меняет RGBA-пиксели и разрешение.
- В пакет включена тема приложения «Уголь и канат».

Проверено штатным импортёром и установлено в **Спутник Windows 1.3.14**. Для установки откройте `cloth-ninja.pet` двойным щелчком либо через **Питомцы → Добавить питомца**. Поддержка этого пакета в macOS 0.2.2 отсутствует.

[Скачать cloth-ninja.pet](https://github.com/GamoffVad/Sputnik/releases/download/pet-cloth-ninja-v1/cloth-ninja.pet) · [Установщик Windows 1.3.14](https://github.com/GamoffVad/Sputnik/releases/download/v1.3.14/Sputnik-1.3.14-Windows-10-11-x64.exe)

Пакет также размещён среди файлов выпуска приложения 1.3.14. В приложенном видео показаны все анимации на чёрном и белом фоне; JSON содержит отчёт проверки, `SHA256SUMS.txt` — контрольные суммы.

Известное ограничение: в начале «Невидимой стены» есть краткий смешанный переход между позами. Начальный и конечный кадры при этом совпадают с общей опорной позой.
