# Спутник 0.2.4 — macOS

- Исправлено раскрытие списка моделей в настройках подключения: список остаётся внутри видимой области окна.
- «Проверить подключение» получает доступные модели, когда ID ещё не выбран. Пустой каталог предлагает ручной ввод; ошибки API показываются без подмены.
- Выбор палитры питомца и её переключатель применяют цвета выбранного персонажа даже после ручной настройки темы. Пользовательская палитра сохраняется.
- В [библиотеке PET](../../PET/README.md) появилась Праздничная ёлка с 10 анимациями и зелёным акцентом в тон хвои. [Скачать `.pet`](https://github.com/GamoffVad/Sputnik/releases/download/v1.3.28.21/Christmas-Tree-10.pet).

Универсальный DMG для Apple Silicon и Intel, macOS 13+. Перенесите приложение в «Программы» с заменой предыдущей версии. Данные в `~/Library/Application Support/Sputnik` и ключ в Связке ключей сохраняются.

Предварительный выпуск с подписью ad hoc, без Developer ID и нотарификации Apple. Перед публикацией образ проходит проверку контрольной суммы, подписи и smoke-тесты на Intel и Apple Silicon.
