# Спутник 1.3.12 для Windows

| Система | Файл |
| --- | --- |
| Windows 10 / 11, 64 бит | `Sputnik-1.3.12-Windows-10-11-x64.exe` |
| Windows 7 SP1, 64 бит | `Sputnik-1.3.12-Windows-7-x64.exe` |
| Windows 7 SP1, 32 бита | `Sputnik-1.3.12-Windows-7-x86.exe` |
| Windows 10 / 11, без установки | `Sputnik-1.3.12-Windows-10-11-x64-Portable.zip` |

Установщики работают офлайн и сохраняют существующие заметки и настройки. В Windows 7 включён .NET Framework 4.8; может понадобиться перезагрузка.

Исправлены наложение чата на настройки и прямоугольные углы матового стекла Windows 11. Добавлены регулировка прозрачности, автоматический предпросмотр сфер, полупрозрачные карточки названий, сетка выбора значков и шевроны «Назад». Убраны лишние рамки ползунков и кнопок; значки больше не обрезаются. Рыцарь-дозорный включён в комплект.

Проверены компоненты WPF, сохранение и закрытие настроек, автоцвет заметок, 2400 раскладок сфер и сборки .NET Framework x64/x86 на текущей Windows. Отдельная проверка на настоящей Windows 7 не проводилась.
