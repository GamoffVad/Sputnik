# Спутник 0.2.0 для macOS

**Скачать:** `Sputnik-0.2.0-macOS-Universal.dmg` — один образ для Apple Silicon и Intel, macOS 13 и новее.

Откройте образ и перенесите **Sputnik** в папку **Программы**. Данные предыдущей версии сохраняются.

## Что изменилось

- Рыцарь-дозорный включён в библиотеку вместе с Кляксой, Кудряшкой и Песчаным дозорным.
- Добавлены автоцвет новых заметок, матовое стекло окна настроек и ползунок прозрачности фона.
- Сохранение оформления и параметров модели закрывает окно.
- Кнопки «Назад» заменены шевронами, сохранение и сброс — значками с подписями при наведении.
- Предпросмотр сфер открывается при изменении размера, интервала и отступа. Открытые сферы не следуют за перемещением питомца.
- Исходники macOS и Windows объединены в основной ветке; сборки и ссылки разделены по платформам.

Предварительный выпуск с локальной подписью **ad hoc**, без Developer ID и нотарификации Apple. Gatekeeper может заблокировать первое открытие; [официальная справка Apple](https://support.apple.com/ru-ru/102445).

Перед публикацией CI проверяет универсальный исполняемый файл, целостность DMG, загрузку питомцев, заметки и переключение интерфейса на Intel и Apple Silicon. Проверки не заменяют полный ручной прогон на всех версиях macOS.
