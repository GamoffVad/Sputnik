# Спутник 1.3.28.28 — Windows

- Вверху контекстного меню мелким шрифтом отображается версия запущенного приложения.
- Окно напоминания стало компактным: размер зависит от содержимого, основной текст заметнее, время вынесено в отдельную строку, кнопка «Готово» выделена. Закрытие доступно крестиком и клавишей Esc.
- Исправлено растягивание уведомлений до размеров окна настроек. Длинный текст прокручивается, кнопки действий остаются доступны.
- Сохраняется импорт больших питомцев: до 2 ГиБ распакованных данных, до 256 файлов. Пакет «Праздничная ёлка» размером 694 433 353 байта проверен на установку: 13 анимаций.
- Сокращено удержание изображений в памяти: плеер и предпросмотр держат текущий и следующий PNG-лист, закрытый предпросмотр освобождает изображения. Портрет и переход сохраняют отдельный кадр вместо целого атласа. Исходные пиксели, разрешение и альфа анимаций сохраняются.
- Выпущены установщики Windows 10/11 x64 и Windows 7 SP1 x64/x86. В установщиках Windows 7 включён автономный .NET Framework 4.8.

Сборки .NET Framework 4.8 проверены в 64- и 32-битных процессах на текущей Windows. Отдельного запуска на настоящей Windows 7 не проводилось.

В изолированном тесте удержание кадра 960×960 из листа ёлки уменьшилось со 152,4 до 43,7 МиБ рабочего набора процесса. Это замер отдельного сценария, а не обещание фиксированного общего расхода памяти: он зависит от выбранного питомца и открытых окон. [Методика и проверки](../fixes/windows-memory.md).

Windows-исходники этого выпуска основаны на проверенном снимке 1.3.28.27; точный код сборки публикуется в теге `v1.3.28.28` и отдельном архиве `Sputnik-1.3.28.28-Windows-source.zip`. Заметки, настройки и пользовательская библиотека в дистрибутив не входят. Питомцы доступны отдельно в [библиотеке](https://github.com/GamoffVad/Sputnik/releases/tag/pets-2026-11-22).
