# Спутник 0.2.7 — macOS

- Переработана вкладка «Движения»: единая кнопка плей/пауза и сохраняемый переключатель случайного порядка.
- Орёл использует масштаб из пакета без принудительного увеличения. Актуальный пакет задаёт размер 2,0 и собственную медно-коричневую тему в тон перьям.
- Поддержан и проверяется реальный пакет Бита с 18 анимациями: десять прежних и восемь новых с анимированными глазами.
- Сохранена привязка меню к видимому силуэту, без отступа от прозрачных полей.

[Скачать обновлённые пакеты Орла и Бита](https://github.com/GamoffVad/Sputnik/releases/tag/pets-2026-11-27). Импорт: «Питомцы» → плюс → `.pet`. Для цвета окон включите палитру питомца.

Универсальный DMG для Intel и Apple Silicon, macOS 13+. Предварительный выпуск с подписью ad hoc, без Developer ID и нотарификации Apple. Публикация происходит после проверки обоих пакетов и запуска образа на обеих архитектурах.
