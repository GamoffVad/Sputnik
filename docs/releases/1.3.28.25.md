# Спутник 1.3.28.25 — Windows

- В библиотеку [PET](../../PET/README.md) добавлена Праздничная ёлка: 10 анимаций 960×960, прозрачность, единая опорная поза и собственная зелёная палитра «Праздничная хвоя».
- Включённая «Палитра питомца» применяется при выборе персонажа, включая переход с пользовательской темы. Сохранённые пользовательские цвета остаются доступны в настройках.
- Установщик Windows 10/11 x64 подготовлен из проверенной актуальной сборки. Точный снимок исходников Windows приложен к выпуску отдельно; исходники macOS находятся в основной ветке.

[Скачать ёлку `.pet`](https://github.com/GamoffVad/Sputnik/releases/download/v1.3.28.21/Christmas-Tree-10.pet). Для уже импортированной ёлки импортируйте обновлённый пакет повторно и включите её палитру.

Настройки, заметки и импортированные питомцы хранятся отдельно от приложения и сохраняются при обновлении.
