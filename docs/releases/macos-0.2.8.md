# Спутник 0.2.8 — macOS

Добавлено примагничивание заметок при перетаскивании за заголовок. Соседние заметки выравниваются по краям и центрам по горизонтали и вертикали; между ними остаётся зазор 12 pt. Скрытые заметки на выравнивание не влияют.

Удерживайте Option для свободного перемещения. Двигается только выбранная заметка. Выровненное положение сохраняется автоматически и восстанавливается после открытия.

Сохранены плей/пауза, переключатель случайного порядка, размер и палитра Орла, 18 анимаций Бита.

Универсальный DMG для Intel и Apple Silicon, macOS 13+. Предварительный выпуск с подписью ad hoc, без Developer ID и нотарификации Apple. Публикация — после запуска готового образа на обеих архитектурах.
