# Спутник 1.3.14 — приложение и питомцы отдельно

В чистой установке осталась только **Клякса** с восемью анимациями. Пакеты **HUDI, Кудряшка, Песчаный дозорный, Рыцарь-дозорный и Тихий ниндзя** скачиваются отдельно из файлов этого релиза рядом с установщиками.

- Двойной щелчок по `.pet` открывает предпросмотр в Спутнике, в том числе если приложение уже запущено. Установка выполняется после подтверждения в этом окне.
- Повторный импорт обновляет питомца и сохраняет предыдущую версию в `pet-backups`. Проигрыватель сразу загружает обновлённые кадры.
- Палитра хранится внутри каждого пакета. Выбор «Применить палитру питомца» переключает приложение на его цвета, включая переход с пользовательской темы.
- При обновлении сохраняются заметки, настройки, импортированные питомцы и активный персонаж. Если активный персонаж раньше входил в установщик, он переносится в пользовательскую библиотеку. Остальные прежние встроенные персонажи доступны отдельными файлами.
- У «Тихого ниндзя» исправлена серая подложка под ступнями в «Тихой связке». Используется общая мягкая тень. Все пять анимаций сохраняют кадры 1280×720, 30 кадров/с и точное совпадение начальных и конечных кадров.
- Фото из заметок больше не пропускаются при подготовке отправки. Для установленного Telegram Desktop используется его команда «Отправить» с выбором получателя. PNG передаются без изменения; текст доступен в буфере для вставки в подпись. Если команда «Отправить» недоступна или используется веб-клиент, фото копируются для Ctrl+V и доступны через «Файлы фото». Обычные ссылки пересылки передают только текст и не могут прикрепить локальный файл.
