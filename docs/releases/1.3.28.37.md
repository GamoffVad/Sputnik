# Спутник 1.3.28.37 — Windows

- Вкладка «Движения»: одна кнопка переключает паузу и воспроизведение, случайный порядок включается и выключается отдельным переключателем и сохраняется между запусками. При выключении движения идут по порядку.
- Орёл использует размер из пакета без принудительного увеличения. В актуальном пакете масштаб 2,0 и собственная медно-коричневая тема «Орлиное оперение» в тон перьям.
- Бит обновлён до 18 анимаций: прежние десять сохранены, добавлены восемь с анимированными глазами. В «Гитарном соло» используется настоящий инструмент.
- В меню питомца добавлено «Скрыть в трей». Щелчок по значку возвращает открытые окна; правой кнопкой доступны быстрый чат и выход. Скрытая анимация приостанавливается, напоминания продолжают работать.

Для нового размера и палитры импортируйте обновлённый пакет орла и включите «Палитра питомца». Настройки, заметки и остальные питомцы сохраняются при обновлении.
