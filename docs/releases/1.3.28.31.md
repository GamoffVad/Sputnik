# Спутник 1.3.28.31 — Windows

- Исправлен пункт «Значок программы» в разделе «Сайты и программы»: значок извлекается из выбранного `.exe`, появляется в предпросмотре, списке избранного и сферах рабочего стола.
- Флажок «Монохромный» применяет палитру приложения к значку программы; исходная форма и прозрачность сохраняются. Цветной режим также работает.
- Источник значка программы сохраняется как `iconSource: app` и восстанавливается при повторном открытии. Явно выбранные значки библиотеки не заменяются.
- При отсутствии значка используется стандартный значок программы, без ошибки формы.

Для программы, добавленной до исправления, откройте её редактирование, выберите «Значок программы» и сохраните.

Проверки: извлечение значка из реального тестового EXE, кириллица и пробелы в пути, цветной и монохромный режимы, сохранение/повторное открытие, список и сфера, выбор библиотеки, отсутствующий файл и отсутствие ресурса значка. Программа-образец не запускается, пользовательские данные не изменяются.

Выпуск включает установщики Windows 10/11 x64 и Windows 7 SP1 x64/x86, переносимую сборку Windows 10/11 и исходники. .NET Framework 4.8 проверяется в обеих разрядностях на текущей Windows; отдельного запуска на настоящей Windows 7 не проводилось.
