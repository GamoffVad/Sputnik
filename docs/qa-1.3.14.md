# Проверки 1.3.14

Проверено 19 ноября 2026 года на текущем Windows-компьютере:

- WPF: восемь переходов между окнами без остаточного изображения; заметки с форматированием, списками, изображением, размером, закреплением и повторным открытием; каналы отправки; настройки модели с имитацией HTTP; напоминания, избранное и горячие клавиши. Команда: `dotnet run --project tests/workspace-check/Check.csproj -c Release -- --components`.
- Пакеты: один встроенный питомец (Клякса), пять отдельно импортируемых пакетов с темами, обновление с резервной копией, версия 2 и viewport, недопустимые пути/размеры. Отдельная проверка `--pet-distribution-only` проверяет открытие файла, смену темы, миграцию активного старого питомца без изменения настроек и чистую установку.
- Фото заметок: исходные PNG сохраняются побайтово и без изменения размеров; экспортируются вложенные изображения и заметки без текста; буфер содержит одно или несколько фото; подготовлены команды старого и нового Telegram Desktop с корректным цитированием путей. Команда `--photo-sharing-only`. Реальный мессенджер тестом не запускается, сообщения не отправляются. Передача через установленный клиент требует пользовательской проверки; веб-ссылка сама по себе не прикрепляет локальные фото.
- «Тихий ниндзя»: 600 кадров 1280×720, пять анимаций по 120 кадров/30 fps; все десять начальных/конечных кадров совпадают пиксель в пиксель, включая настоящий WPF-рендер. 16 PNG-листов остальных четырёх анимаций не изменены побайтово при исправлении тени «Тихой связки». SHA-256 `.pet`: `3d85c74e0626d2c609d82bfaa3551e9e0e66d6ea1c891189f70a2a841db15ca0`.
- Сборки .NET 10 x64 и .NET Framework 4.8 x64/x86 проходят `installer/Test-Payload.ps1`: архитектура PE, версия, зависимости, только Клякса/8 PNG, отсутствие WebView2. Запуск на физической Windows 7 не проверялся.

Пакет «Тихий ниндзя» отвергается фактической опубликованной Windows 1.3.12 (96 МиБ, только схема 1); 1.3.13 и 1.3.14 поддерживают схему 2, viewport и 256 МиБ. macOS 0.2.2 этот пакет не поддерживает.

Позднее в тот же день у версии пакета 2 дополнительно убран светлый след вдоль подошвы «Тихой связки». Остальные 16 PNG-листов сохранены побайтово; общие конечные кадры не изменены. Новый SHA-256: `a0e97cb70740a430835196a774ed1bbe04e964a9d2611c95b42cbd631cd4d223`. Файлы `.pet`, каталога и контрольных сумм обновлены отдельно от установщиков.
