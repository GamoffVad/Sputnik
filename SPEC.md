# Спутник — спецификация и план реализации

## Назначение

Локальное приложение Windows с интерфейсом на WPF. Рабочее пространство объединяет анимированного питомца, заметки, избранное, напоминания и чат с моделью.

Исходные макеты находятся в Sputnik-mockups. Продукт открывается на русском. Темы «Графит» для HUDI и «Сирень» для Кудряшки задают акцент, фон, поверхности и оформление сфер. Элементы интерфейса рисуются своими стилями, семантические кнопки и поля сохраняют поддержку клавиатуры.

## Поведение

- **Питомец на рабочем столе.** Прозрачное WPF-окно показывает текущего питомца поверх окон. Каждое движение проигрывается один раз за круг, затем порядок перемешивается. HUDI использует плавное движение ожидания. Левый щелчок плавно раскрывает сферы вокруг питомца. Они перемещаются вместе с ним, учитывают рабочую область текущего монитора и плавно исчезают по щелчку снаружи. Автозапуск включается в разделе «Управление».

- **Контекстное меню.** Правый щелчок на питомце открывает меню рядом с ним. Быстрый и полный чат, заметки, избранное, напоминания, движения, питомцы, внешний вид, модель и управление открываются по одному в компактном окне. Три щелчка открывают быстрый чат, Ctrl + двойной щелчок открывает заметки.
- **Библиотека.** Встроенные HUDI и Кудряшка. Доступен выбор питомца и его темы. Вкладка «Питомцы» в настройках содержит кнопку «Выбрать питомца». После выбора файла пользователь видит предпросмотр, список движений, кадры выбранного движения и оформление. Только «Загрузить» добавляет питомца в библиотеку и активирует его. Повреждённый пакет показывает ошибку.
- **Заметки.** Создание, редактирование, поиск, закрепление и удаление. Черновик сохраняется локально.
- **Избранное.** Отдельные вкладки для сайтов и Windows-приложений. Сайты открываются в системном браузере по HTTP(S). Приложение выбирается через диалог Windows и запускается только явной кнопкой, без командной строки. Библиотека содержит ровно 100 значков с поиском, категориями, предпросмотром и палитрой питомца.
- **Напоминания.** Название, время, повтор, выполнение и откладывание на 10 минут. Оповещение рядом с питомцем доступно при открытом приложении. Просроченные напоминания показываются при следующем запуске.
- **Чат.** Быстрый и полный чат используют одну историю. Администрирование настраивает базовый URL, ID модели и API-ключ. Первая версия поддерживает совместимый с OpenAI Chat Completions HTTP API, включая локальный сервер. Настоящие запросы отправляются только после ввода настроек и явного действия пользователя. При отсутствии подключения интерфейс объясняет, как подключить провайдера.
- **Хранение.** Библиотека, заметки, избранное, напоминания, пользовательские параметры и история чата хранятся локально в профиле Windows. API-ключ хранится в зашифрованном виде средствами Windows для текущего пользователя. Клиент получает только признак наличия сохранённого ключа. В первой версии уведомления привязаны к запущенному приложению.

## Формат .pet, версия 1

Пакет ZIP с расширением .pet. В корне находится manifest.json с полями schemaVersion (1), id (латинский идентификатор), name, description, theme (name, accent, background, surface, цвета #RRGGBB) и animations. Для каждой анимации поле name содержит название, file — путь к PNG-листу, frameWidth/frameHeight — размер ячейки, columns — число колонок, frameCount — число используемых кадров, fps — частота воспроизведения. Кадры читаются слева направо и сверху вниз. Порядок записей определяет порядок в списке движений. Первый кадр первой анимации используется как обложка. PNG могут содержать альфа-канал. Пакет содержит только данные. Идентификаторы встроенных питомцев зарезервированы. Импорт проверяет схему, геометрию, пути и размеры изображений.

## План реализации и приёмки

1. Собрать нативные окна WPF и темизацию. Проверить запуск Windows и клавиатурную навигацию.
2. Подключить четыре существующие анимации Кудряшки, встроенный HUDI и библиотеку значков. Сделать рендер кадров без растягивания и предпросмотр импортируемого архива.
3. Довести полный сценарий .pet от выбора файла до повторного запуска с выбранным питомцем. Вложить пример пакета с реальными спрайтами Кудряшки.
4. Подключить заметки, избранное и напоминания к локальному хранению. Проверить редактирование, смену темы, поиск значков, выполнение и откладывание.
5. Реализовать чат, настройки провайдера, проверку соединения и сообщения об ошибках. Проверить запросы с тестовым локальным сервером без пользовательского ключа.
6. Собрать Release, запустить приложение, снять скриншоты при обычной и узкой ширине. Зафиксировать способ запуска и ограничения в README.

Отдельным этапом возможны системные уведомления при закрытом приложении, синхронизация между устройствами и подключение других протоколов LLM.
