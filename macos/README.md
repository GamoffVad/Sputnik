# Спутник для macOS

Приложение рассчитано на macOS 13 и новее. Универсальный `.app` включает бинарники для Apple Silicon и Intel, изображения питомцев и интерфейс настроек. После скачивания для установки интернет не нужен.

## Установка

1. Откройте образ `SputnikSetup-<версия>-macos-universal.dmg` и перетащите **Sputnik** в папку «Программы».
2. Откройте **Sputnik** из папки «Программы». В предварительных выпусках используется подпись ad hoc. Если система блокирует открытие, для доверенной копии разрешите её в разделе «Конфиденциальность и безопасность».
3. Щёлкните по питомцу правой кнопкой для доступа к меню. Через «Питомцы → Добавить питомца» можно импортировать совместимый пакет `.pet`, например [Рыцаря-дозорного](https://raw.githubusercontent.com/GamoffVad/Sputnik/main/pets/knight-watchman.pet).

Данные хранятся в `~/Library/Application Support/Sputnik`. Ключ модели хранится в Связке ключей macOS. Для облачных запросов и автоматического получения значков сайтов нужен интернет. Для работы с местным LLM можно задать адрес его OpenAI-совместимого API.

Заметки открываются в компактном редакторе. Настраиваемые системные горячие клавиши из Windows пока не перенесены.

## Сборка

На Mac с Xcode или Command Line Tools выполните в корне репозитория:

```bash
bash macos/build.sh 0.1.0
```

Образ и его контрольная сумма появятся в `artifacts/macos`. GitHub Actions собирает и тестирует образ на macOS. Теги вида `macos-v0.1.0` публикуют отдельный предварительный выпуск для Mac.
