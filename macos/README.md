# Спутник для macOS

Приложение рассчитано на macOS 13 и новее. Универсальный `.app` включает бинарники для Apple Silicon и Intel, изображения питомцев и интерфейс настроек. После скачивания для установки интернет не нужен.

## Установка

1. Откройте образ `SputnikSetup-<версия>-macos-universal.dmg` и перетащите **Sputnik** в папку «Программы».
2. Откройте **Sputnik** из папки «Программы». Выпуск 0.1.0 подписан ad hoc и может блокироваться Gatekeeper. Для доверенной копии 0.1.0 см. [инструкцию Apple по открытию приложения](https://support.apple.com/ru-ru/102445). Для новых выпусков процесс публикации требует подпись Developer ID и нотарификацию Apple.
3. Щёлкните по питомцу правой кнопкой для доступа к меню. Через «Питомцы → Добавить питомца» можно импортировать совместимый пакет `.pet`, например [Рыцаря-дозорного](https://raw.githubusercontent.com/GamoffVad/Sputnik/main/pets/knight-watchman.pet).

Данные хранятся в `~/Library/Application Support/Sputnik`. Ключ модели хранится в Связке ключей macOS. Для облачных запросов и автоматического получения значков сайтов нужен интернет. Для работы с местным LLM можно задать адрес его OpenAI-совместимого API.

Заметки открываются отдельными окнами. Можно менять цвет, размеры и положение стикеров, форматировать текст и скрывать все заметки из меню питомца. Сочетания для разделов можно задать в меню «Управление».

## Сборка

На Mac с Xcode или Command Line Tools выполните в корне репозитория:

```bash
bash macos/build.sh 0.1.1
```

Образ и его контрольная сумма появятся в `artifacts/macos`. Локальная сборка по умолчанию подписывается ad hoc и предназначена для тестирования. GitHub Actions собирает и проверяет приложение на Intel и Apple Silicon.

Для публикации настройте секреты репозитория GitHub.

| Секрет | Значение |
| --- | --- |
| `MACOS_CERTIFICATE_BASE64` | Экспорт сертификата Developer ID Application с закрытым ключом в формате P12, закодированный в Base64 |
| `MACOS_CERTIFICATE_PASSWORD` | Пароль файла P12 |
| `APPLE_TEAM_ID` | Идентификатор команды Apple Developer |
| `APPLE_ID` | Apple Account с доступом к команде |
| `APPLE_APP_SPECIFIC_PASSWORD` | Пароль приложения для службы нотарификации |

Запустите workflow **macOS build** с новой версией и включённым параметром `publish` или создайте новый тег `macos-v<версия>`. Перед публикацией workflow подписывает приложение и DMG, отправляет образ в Apple, прикрепляет билет и проверяет образ через Gatekeeper на обеих архитектурах.
